## 📌 Internship Overview
This repository contains the completed tasks for the **Frontend Development Internship** at **CodeAlpha**. The internship focuses on building responsive, interactive, and beautifully designed web applications using core web technologies: HTML, CSS, and vanilla JavaScript. 

## 🎯 Projects Included

This repository includes the implementation of the 4 assigned projects:

### [✅ TASK 1: Image Gallery](./Image%20Gallery/)
A fully responsive image gallery featuring a lightbox view.
- Designed with HTML and CSS layout.
- JavaScript implemented for navigation (next/prev buttons) and lightbox functionality.
- Includes smooth hover effects and transitions.

### [✅ TASK 2: Build a Calculator](./Calculator/)
A fully functional basic calculator.
- Supports all core arithmetic operations (+, −, ×, ÷).
- Clean user interface with responsive buttons and a dynamic display screen.
- Handles user input, screen clearing, and real-time result calculation.

### [✅ TASK 3: Build Your Own Portfolio Site](./Portfolio/)
A personal portfolio website showcasing skills and projects.
- Clean, responsive layout with dedicated sections (About, Projects, Contact).
- Features smooth scrolling, entrance animations, and hover effects.

### [✅ TASK 4: Music Player using JavaScript](./Music%20Player/)
A modern, liquid glass-themed music player.
- Custom user interface styled with advanced CSS (glassmorphism).
- Complete JavaScript audio control (play, pause, next, previous).
- Features dynamic backgrounds based on album art, interactive progress bar, and volume controls.
- Dynamic queue/playlist overlay with autoplay features.

---

## 🛠️ Technologies Used
- **HTML5**: Semantic page structure
- **CSS3**: Advanced styling, Flexbox/Grid layouts, Glassmorphism effects
- **JavaScript (ES6+)**: DOM manipulation, HTML5 Audio API, interactive logic
